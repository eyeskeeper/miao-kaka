# 管理后台：公告广播 + 数据看板 设计文档

- 日期：2026-09-25
- 状态：已实现并冒烟通过
- 关联：通知中心（user_notification type=3 系统公告）、admin 用户管理

## 一、公告系统

- **发布**：`POST /admin/announcement` body `{title ≤64, content ≤512}`（@AuthCheck admin）
- **广播**：公告落库 `announcement` 表为事实源，同事务复制通知行（type=3、ref_id=公告id、未读）到**每个未删除用户**的通知中心
- **历史**：`GET /admin/announcements?current=&pageSize=`（最新在前，每页 ≤50）
- 普通用户调用 → 40101（类级 @AuthCheck 拦截）；空标题/内容 → 40000

## 二、数据看板

`GET /admin/stats` → AdminStatsVO：

- 用户：累计（未删除）、今日新增
- 打卡量：今日 / 昨日 / 本周（周一至今）/ 累计；**DAU**：当日打卡去重人数（今日/昨日）
- 局数：招募中 / 进行中 / 已结算
- 趋势：近 7 天全站每日打卡次数
