# 审核上诉与死斗举报设计（救济通道分层：组长仲裁 → 平台终裁）

> 归档日期：2026-11-09。后端 470aa72；前端见前端仓库提交。
> 救济仅针对**驳回**结果；通过的结果不可上诉/举报。

## 一、通道分层

| 场景 | 通道 | 前置校验 |
| --- | --- | --- |
| 互审局被驳回 | 48h 内**上诉**（每凭证 1 次，uk_evidence 兜底）→ 组长仲裁 | 局 RUNNING、凭证=本人+REJECTED、驳回时间 ≤48h、本人在册 |
| 互审局上诉被维持 | 可**举报**（每人每局 1 次，uk_duel_reporter 兜底） | 该凭证 appeal.status=2 |
| 组长局被组长驳回 | 直接**举报**（每人每局 1 次） | 凭证=本人+REJECTED |
| 已结算/已解散局 | 两通道全关 | 结算/解散流程将未决上诉批量置失效（维持原判） |

## 二、组长仲裁（`⚖ 上诉待处理`）
- 详情页独立卡（互审局组长）：凭证图+原驳回理由+上诉理由+仲裁截止时间
- 【改判通过】/【维持驳回】；**超 48h 未仲裁由每小时定时任务自动改判通过**（resolveOverdue，与超时自动通过同哲学：不作为的代价由不作为方承担）
- 维持后通知上诉人"可升级举报"

## 三、改判通过（组长仲裁 / admin 终裁 / 超时自动共用 `applyReversal`）
1. evidence REJECTED→APPROVED（条件更新抢占，reviewer=改判人，备注记链路）
2. 押金局补回被追回的当日份额：`refund(deposit/totalDays)` + `member.refunded` 等额加回
3. `restoreRejectedCheckIn`：record ABNORMAL→NORMAL + 连击回溯 + **补发一次猫事件结算**（与正常通过完全等价——新拆的 finalizeCheckIn 与 settleApprovedCheckIn 共享内核）
4. 通知当事人（type 9）；duelAgg 缓存逐出
5. 公示：审核记录卡该条追加 **"⚠ 已被改判"** 红标（ReviewHistoryVO.overturned，联查 appeal+report 双来源覆盖组长局）

## 四、admin 终裁（管理后台「🚨 举报处理」页签）
- 分页列表：凭证图+举报理由+原驳回理由+审核人+上诉链（维持/改判经过）+局状态
- 【改判通过】仅限局 RUNNING 且提交者在册（离局者影子计划已下架无从结算）；已结算局只能存档（status=3 无法处理）
- 【维持原判】结案
- **误判零经济处罚（用户定版）**：仅留痕——互审局举报改判时原派单审核人与组长**双留痕**（"仲裁失职连带"）；组长局改判留痕组长；维持不追责

## 五、数据模型（2026-11-09 增补）
- `evidence_appeal`：uk(evidence_id)；status 0待仲裁/1改判/2维持/3超时自动改判
- `duel_report`：uk(duel_id, reporter_id)；status 0待处理/1改判/2维持/3无法处理

## 六、通知类型
- 8=收到凭证上诉（→组长，提示 48h 时限）；9=上诉/举报处理结果（→当事人）

## 七、冒烟结论（全部通过）
- 互审押金局全链：B 被驳回（追回14）→ 上诉 → 组长改判：补钱(528→542)、refunded(0→14)、record NORMAL、猫事件(exp+10/streak1)、history overturned ✓
- 上诉被维持 → 举报放开；未上诉先举报被拒；二次举报被每局一次拦截 ✓
- admin 改判（互审局）：双留痕文案"原审核人 xx；组长 xx 仲裁失职连带"；A 补钱+事件结算 ✓；admin 维持 → 通知"举报已处理：维持原判" ✓
- 组长局：上诉被拒（提示直接举报）→ 直接举报成功 ✓
- 已结算局举报改判 → status=3"局已结算/解散，无法改判（存档）" ✓
- 越权矩阵：49h 外上诉拒 / 非本人凭证拒 / 重复上诉 uk 拒 / 非组长仲裁拒 ✓
- 超时自动改判：造 49h 前待仲裁数据，定时任务触发 appeal status=3、凭证改判、record 恢复、组长补钱（100→114）✓
- 回归：审核/派单/解散路径不回归（invalidatePending 接入结算与解散，逻辑为单条 update 未单独造局验证）

## 八、明确不做
通过结果反向举报、经济处罚、误判计数展示（成员列表不贴污点标签）、已结算局追溯重算、举报的 admin 实时推送（后台页签可见即可）
