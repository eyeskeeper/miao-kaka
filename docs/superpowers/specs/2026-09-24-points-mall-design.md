# 积分商城（补卡券 + 双倍经验卡）设计文档

- 日期：2026-09-24
- 状态：已实现并冒烟通过
- 关联：补卡（makeup 扣积分）、打卡事件引擎（经验结算）

## 一、需求与口径

积分商城 v1 上架两件商品（拷问定版）：

| code | 名称 | 价格 | 效果 |
| --- | --- | --- | --- |
| MAKEUP_VOUCHER | 补卡券 | 100 积分 | 补卡时选择使用，免扣 50 积分 |
| DOUBLE_EXP | 双倍经验卡 | 80 积分 | 打卡时自动消耗一张，本次经验 ×2 |

商品目录 v1 代码内定义（`MallConstant`：code/name/price/desc）；背包为 `user_item` 表（unique uk_user_item，数量条件更新保证不为负）。积分保持既有直接扣减模式（无流水表），扣减用**条件更新 `total_points >= price` 原子扣减**防并发透支，成功后逐出用户缓存。

## 二、接口（MallController，/mall，需登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/mall/catalog` | 商品清单 + 我的持有数 |
| GET | `/mall/bag` | 我的背包（仅持有 >0 的道具） |
| POST | `/mall/buy` | body `{itemCode}`；余额不足 40000「积分不足，购买『xx』需要 N 积分」 |

## 三、消耗链路

- **补卡券**：`CheckInMakeupRequest.useVoucher=true` 且持有券 → `consumeItem` 条件扣减（quantity>0 → -1）→ 免扣积分（`pointsCost=0`、`voucherUsed=true`）；无券或未选择走原积分扣减。原子：券消耗与补卡同事务
- **双倍经验卡**：打卡结算时自动消耗（有则 `expGained ×2`，`doubleExp=true`），无需手动激活——用户买来即用

## 四、冒烟结果

| # | 用例 | 结果 |
| --- | --- | --- |
| 1 | 目录：两件商品价格/描述/持有数正确 | ✓ |
| 2 | 购买：扣积分（500→400→320）+ 背包 +1 | ✓ |
| 3 | 余额不足：80 分买 100 分商品 → 40000「积分不足，购买「补卡券」需要 100 积分」 | ✓ |
| 4 | 双倍经验：打卡 expGained=20（10×2）、doubleExp=true、背包 -1 | ✓ |
| 5 | 补卡券：pointsCost=0、voucherUsed=true、券 -1 至 0；意外之喜：首次补卡同时解锁「不弃不离」徽章 | ✓ |

## 五、明确不做

连击保护卡（断签回溯语义复杂，二期）、装扮类商品（无皮肤系统）、补卡券自动优先消耗（用户显式选择）、退款/退货
